# My Discord Bot

After a long absence, I decided to build a simply bot. Enjoy! :D

A simple Discord bot built with discord.py.

## Commands
- /hello - greets you
- /coinflip - flips a coin
- /add - adds two numbers
- /8ball - answers your question

## Setup
1. Create a virtual environment and run `pip install -r requirements.txt`
2. Create a `.env` file with `DISCORD_TOKEN=your_token`
3. Run `python bot.py`
